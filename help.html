Trainer Control — Guide

A fast, local workout builder for indoor cycling: build a workout, connect your trainer over Bluetooth, ride. No account, no cloud requirement — all data stays on your device.

🧩 Requirements

  • Browser: Chrome or Edge (desktop, macOS/Windows/Linux/ChromeOS). The app uses Web Bluetooth for the trainer/sensor connection — Safari and Firefox don't support this yet.
  • Trainer: a smart trainer with FTMS support (Bluetooth "Fitness Machine Service") — most current Wahoo, Tacx and Elite trainers offer this.
  • Optional: a Bluetooth heart rate strap (standard "Heart Rate" profile) and/or a Zwift Click/Play/Ride controller for shifting/steering input.

🔗 Connecting trainer & sensors

  1. Click ● Connections in the top right.
  2. Turn on the switch next to "Smart Trainer" — Chrome opens the Bluetooth device picker, select your trainer there.
  3. Do the same for "Heart Rate Strap" and "Controller (Zwift Ride)" if you have them.
  4. A green dot next to "Connections" shows that at least the trainer is connected.
The trainer and heart rate strap pair independently of each other — for a strap that should also stay connected to a sports watch at the same time, see Troubleshooting.

🛠️ Building a workout

The Workouts tab is the app's home screen.

  1. Add steps at the top: + Steady (constant power), + Ramp ↑ / + Ramp ↓ (rising/falling), or + Free Ride (no target).
  2. Quick presets via the zone chips (Z1 Z2 Z3 Z4 Z5 Z6) — adds a step directly in that zone.
  3. In the graph, steps can be moved by drag and drop, and the duration can be changed by dragging the right edge of a bar.
  4. Below the graph, the table lists every step individually with name, duration, type (Steady/Ramp/Free Ride), value mode (watts or % FTP) and target value — everything can be adjusted precisely via input field instead of the mouse here.
  5. Enter a name at the top and click Save — the workout lands in the Library at the bottom, alongside the built-in presets.

🔁 Repeat blocks

For intervals that repeat several times (e.g. "6× 1 min hard / 1 min easy"):

  1. Drag the violet Block element from the toolbar onto the graph — or click + Block in the steps table below.
  2. Drag the desired steps into the block — they get visually enclosed.
  3. Set the repeat count (×N) on the block.
  4. The copy button on a block duplicates the whole block, including all steps it contains.

🚴 Riding live

  1. The trainer must be connected (see above), otherwise a notice appears.
  2. Choose a workout in the library or leave it open in the editor, then click ▶ Start.
  3. Tap Start now in the preview overlay — a 10-second countdown follows, giving you time to get on the bike and clip in before the ERG load is actually applied.
  4. While riding: Pause/Resume, adjust intensity live with −/+, ⏹ End to stop early.
  5. When it ends, the app asks whether to save the session to History.

⚙ Settings: FTP, weight, heart rate

Click ⚙ Settings in the top right.

  • FTP (watts) — the basis for all %FTP targets and zone boundaries.
  • Weight (kg) — for the W/kg display while riding.
  • Resting HR and Max HR — together these give the heart rate reserve (Karvonen formula) for the HR zone display.

📁 Backup folder & data

By default, all data lives only locally in the browser. So nothing gets lost (e.g. when removing the Chrome extension), you can connect any folder on your own computer as a backup target.

  1. At the bottom of the Settings panel, click Choose folder.
  2. Pick a folder and confirm the "read & write" permission.
  3. From then on, the app automatically writes a trainer-control-backup.json file to that folder on every change.
  4. After a browser restart, the permission may have been reset — then 🔒 Reconnect appears, one click is enough.
  5. ⬆ Restore from backup lets you deliberately pull the saved state back at any time (with a confirmation prompt, never overwrites anything automatically).
Tip: if you choose your local Dropbox, iCloud Drive or Google Drive folder, the backup syncs automatically across multiple devices — without the app itself ever touching a cloud.

⇅ Export / Import / ZWO

  • In the library: Share saves all your own workouts as .zwo files in one ZIP, Import reads either such a JSON backup or a single .zwo file (file type is detected automatically).
  • In the workout editor: ↓ As .ZWO (Zwift / Garmin) downloads the currently open workout as a .zwo file — directly usable in Zwift & compatible apps. For Garmin watches it takes a detour: import the file into Garmin Connect with the separate, free "Garmin Workout Importer" Chrome extension, from there it syncs wirelessly to the watch.

🔧 Troubleshooting

Heart rate strap won't connect at the same time as a sports watch

Some straps (e.g. Garmin HRM-Dual/HRM-Pro) do support multiple simultaneous Bluetooth connections, but are sensitive to order: connect the watch first, then pair the strap in this app. The reverse doesn't work reliably on some devices.

"Web Bluetooth is not supported"

Use Chrome or Edge, on macOS/Windows/Linux. Safari and Firefox don't currently support Web Bluetooth.

Backup folder button doesn't respond / status stays "Access expired"

Chrome requires active confirmation for file-system access again after every restart. Click 🔒 Reconnect once.

All data (workouts, history, settings) lives locally in browser storage. Without a connected backup folder, it's lost if browser data or the extension is removed — a connected backup folder is therefore recommended.
