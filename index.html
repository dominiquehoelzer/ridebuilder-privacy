Privacy Policy

RideBuilder — Last updated: October 1, 2026 · Guide / Support

Summary

✓ No data is collected, stored, or transmitted — neither by us nor by third parties.

RideBuilder is a purely local application. It runs no server of its own, no analytics or tracking services, and sends no usage, performance, or health data anywhere.

What data is processed

  • Workout, history, and profile data (e.g. FTP, weight, heart rate, ridden sessions) are stored exclusively in your browser's local storage (localStorage) on your own device.
  • Bluetooth connections (smart trainer, heart rate strap, Zwift controller) run directly between your device and the respective sensor via the browser's Web Bluetooth feature. The extension itself does not additionally see or store this connection.
  • Backup folder (optional): if you deliberately choose a folder on your computer in Settings, the app writes a backup file there. This happens exclusively locally via the browser's file system feature — never over the internet.

What does NOT happen

  • No transmission to a server run by the developer or any third party.
  • No analytics, tracking, or advertising services.
  • No user account, no login, no cookies for tracking purposes.
  • No sharing of data with third parties — there is simply nothing to share.

Deleting your data

Since all data is exclusively local, uninstalling the extension or clearing the browser/website data for this page is enough to completely remove all data. A previously connected backup folder is unaffected by this and must be deleted separately if needed.
